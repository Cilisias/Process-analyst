# Портфолио проектов по бизнес-аналитике

## Обо мне

8 лет проработала с процессами в госсекторе — имущество, земля, контракты, инвестпроекты с бюджетами под 10 млрд руб. Со временем стало тесно: хотелось работать не ради галочки, а быстрее, эффективнее и видеть, как твоя работа влияет на результат. Поэтому ушла в коммерцию. Сейчас занимаюсь проектированием и автоматизацией бизнес-процессов, работаю с BPMN, Python, VBA, SQL, 1С:ДО, ELMA365, Jira и Confluence. Внедряю LLM в процессы — промпты, автотранскрибация, автогенерация документов. 

**Ключевые навыки:**
- Процессное управление: BPMN 2.0, EPC, AS-IS/TO-BE mapping, реинжиниринг, регламентация
- Автоматизация и данные: Python (pandas, docx), VBA, SQL, MS Access, 1С:ДО, ELMA365
- Управление требованиями: сбор, формализация, написание ТЗ, тестирование прототипов
- Коммуникации: взаимодействие с органами власти, инвесторами, проведение совещаний высокого уровня
