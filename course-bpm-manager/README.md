# Менеджер бизнес-процессов

> Практические задания и учебные проекты

---

## 🧠 Что отрабатывалось

**Моделирование процессов**
- Описание AS-IS и проектирование TO-BE в BPMN 2.0 / IDEF0
- Выявление узких мест и точек роста через анализ по чек-листу
- Построение диаграммы Исикавы для поиска первопричин проблем

**Анализ и диагностика**
- Стоимостной анализ ABC — расчёт прибыли/убытков по сценариям выполнения процесса
- Расширенный SWOT-анализ — перекрёстный анализ внешних и внутренних факторов
- Построение матрицы RACI — визуализация зон ответственности и границ процесса
- Приоритизация гипотез по устранению первопричин

**Разработка и внедрение KPI**
- Формулировка целей процесса через KPI
- Привязка KPI к SLA и зонам ответственности
- Оценка эффективности процессов через количественные метрики
- Разработка системы мотивации сотрудников на основе KPI

**Управление изменениями**
- Оценка готовности организации к изменениям (модель зрелости процессов)
- Гибридная модель управления изменениями (Коттер + ADKAR)
