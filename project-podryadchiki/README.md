# Бизнес-процесс управления подрядчиками

> Выстраивание сквозного процесса с нуля: от анализа до автоматизации

## 🧩 Артефакты

**Модели и схемы**
- [`BPMN_Цикл_работы_с_подрядчиками.pdf`](./BPMN_Цикл_работы_с_подрядчиками.pdf) — схема бизнес-процесса по работе с подрядчиками
- [`BPMN_схема_AS_IS_оформление_подрядчика.pdf`](./BPMN_схема_AS_IS_оформление_подрядчика.pdf) - схема AS IS подпроцесса оформления подрядчиков (две стадии согласования привлечения, отсутствие актуальных шаблонов договоров NDA, последовательное согласование документов, перегруженные цепочки согласований)
- [`BPMN_схема_TO_BE_оформление_подрядчика.pdf`](./BPMN_схема_TO_BE_оформление_подрядчика.pdf) - схема TO BE подпроцесса оформления подрядчиков (внедрено централизованное хранилище с актуализацией типовых форм договоров и NDA, исключен этап согласования с директором по производству, последовательная модель согласования заменена на параллельную, сокращены цепочки согласований).
- [`BPMN_схема_AS_IS_Согласование закрывающих документов.pdf`](./BPMN_схема_AS_IS_Согласование закрывающих документов.pdf) - схема AS IS подпроцесса согласования закрывающих документов (дублирующие согласования у РП/РН, SLA отсутствует, перегруженные цепочки согласований, последовательное согласование документов) 
- [`BPMN_схема_TO_BE_Актуализация_бюджета.pdf`](./BPMN_схема_TO_BE_Актуализация_бюджета.pdf) - схема TO BE подпроцесса согласования бюджета для оплаты работ подрядчика (перепроектирована цепочка согласований внутри Jira, разработана новая форма расчета)

**Прочее**
- [`AS_IS_расчет_бюджета_на_подрядчика.xlsx`](./AS_IS_расчет_бюджета_на_подрядчика.xlsx) — пример старой формы расчета бюджета на привлеченного подрядчика (ручной перенос данных, дублирующие строки, ручные расчеты)
- [`TO_BE_ver1_расчет_бюджета.xlsx`](./TO_BE_ver1_расчет_бюджета.xlsx) — новый формат расчета бюджета на привлеченного подрядчика (первая редакция: совмещение расчетов TM и FIX-подрядчиков, использование сводных таблиц, сложные формулы, автоматический перенос данных между листами таблицы)
- [`БП_Подрядчики_Обзор.pptx`](./БП_Подрядчики_Обзор.pptx) — пользовательская инструкция-обзор на роль администратора проекта в бизнес-процессе работы с подрядчиками
