# Скрипты автоматизации рутинных задач

- [Скрипты по автоматизации РИД →](./scripts/ria-automation/) - Python-скрипты для подготовки комплекта документов по отказу от результатов интеллектуальной деятельности (автоматическое заполнение шаблонных документов персональными данными и реквизитами проектов)

- [`sborka_zip.py`](./sborka_zip.py) — Python-скрипт для массовой сборки zip-архивов по заданной структуре и наполнению
  
- [`Макрос_сортировка_zip.xlsm`](./Макрос_сортировка_zip.xlsm.xlsm) — VBA-скрипт, распределяющий массив zip-архивов по 3м папкам в соответствии с содержанием конкретного xml-файла внутри него. На выходе - массив zip-архивов, распределенный по 3м папкам + excel-таблица с соотнесением имени zip-архива и содержащегося внутри объекта

- [`GetDataFromMultipleFiles.xlsm`](./GetDataFromMultipleFiles.xlsm) — VBA-скрипт, импортирующий в excel-таблицу информацию, содержащуюся в xml-файле
