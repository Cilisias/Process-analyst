# Автоматизация подготовки документов по отказу от результатов интеллектуальной деятельности (РИД)

- [`word+table_акт_приемки_РИД.py`](./word+table_акт_приемки_РИД.py) — подготовка акта приемки РИД по шаблону (сложность заключалась в автогенерации таблицы: для каждого участника она была уникальной по количеству строк и содержанию).
- [`all.py`](./all.py) — подстановка и форматирование списка участников разработки (по шаблону, служебное задание и акт приемки передачи РИД)
- [`byPerson`](./byPerson.py) — подготовка 4х шаблонных документов на каждого участника команды разработки
