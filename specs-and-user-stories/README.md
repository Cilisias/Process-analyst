# 📄 Технические требования и постановки для разработчиков

В этой папке собраны документы, которые использовались как исходный материал для автоматизации процессов в ЕГРН. На их основе разрабатывались RPA-решения, кликеры и автоматические проверки.

- [`RPA-requirements-pkvvd.pdf`](./RPA-requirements-pkvvd.pdf) Пошаговое описание процесса заведения заявок в ПК ПВД. Использовалось как исходный материал для разработки RPA-кликера, автоматизирующего рутинные операции при регистрации обращений. 

- [`RPA_requirements_egrn_territorial_zones.pdf`](./RPA_requirements_egrn_territorial_zones.pdf) Workflow внесения сведений о территориальных зонах в ЕГРН. Передан разработчику для создания RPA-решения, автоматизирующего обработку заявок (изменение топологии, проверка пересечений, ручной ввод). 

- [`EGRN-easement-requirements-spec.pdf`](./EGRN-easement-requirements-spec.pdf) Технические требования к пакету документов по сервитуту: структура ZIP-архива, заполнение XML-элементов, проверка корректности данных. Использовалось как спецификация для разработки автоматизированной проверки входящих пакетов.
